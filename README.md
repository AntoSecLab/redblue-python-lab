# 🛡️Red Blue Python Lab

> Laboratoire d'apprentissage Python appliqué à la cybersécurité offensive et défensive, dans un environnement virtualisé isolé (VMware).

## Objectifs

- Apprendre le langage Python en profondeur
- Construire un lab réseau d'entreprise réaliste (VLANs, AD, DNS, DHCP)
- Développer des outils offensifs (Red team) en Python from scratch
- Mettre en place des outils défensifs (Blue team) pour détecter ces attaques
- Documenter l'ensemble comme un projet de portfolio professionnel

## Avertissement

Tous les outils de ce repo sont destinés à être utilisés **uniquement** sur un lab virtuel isolé. Leur utilisation sur un réseau tiers sans autorisation écrite est **illégale** (article 323-1 du Code pénal français).
